# Gallery / Helix images

Drop your real photos here and reference them in `src/config.js`.

Recommended: 1200x1500 JPG/WebP for gallery, 1000x1250 for helix cards.

If a file is missing, the site automatically falls back to a generated
gradient texture, so nothing breaks. To use remote URLs instead, set them in
`src/config.js` (the loader works with any CORS-enabled image URL).
